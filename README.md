## 1. Introduction

The Student Exam & Results Management System is a Python-based
project designed to help manage student information and examination
results efficiently.

The system demonstrates the application of Object-Oriented
Programming (OOP) concepts in developing a student results
management program.

## 2. Problem Statement

Managing student records and examination results manually can
be time-consuming and difficult to organize. This project aims
to provide a simple program for organizing student information,
recording results, and monitoring academic performance.

## 3. Project Objectives

The objectives of this project are:

1. To create and manage student records.
2. To assign unique identification numbers to students.
3. To record and manage examination results.
4. To calculate students' average scores.
5. To organize academic information efficiently.
6. To demonstrate Python programming and OOP concepts.

## 4. Technologies Used
